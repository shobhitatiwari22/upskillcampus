## 🛠️ Project Portfolio Technical Summary

### 1. Indian Crop Yield Prediction Pipeline
*   **Domain:** Agricultural Data Engineering & Predictive Modeling
*   **Core Model:** Random Forest Regressor Matrix
*   **Evaluation Metric:** **96.6% Accuracy Index** on out-of-sample data splits.
*   **Key Engineering Highlight:** Solved severe data sparsity issues in raw cultivation records by implementing a global data-shaping architecture via long-format transformation (`pd.melt()`), expanding the viable training data footprint to 4,272 dense entries. Maps correlation vectors between cultivation investments (C2 costs) and final crop output metrics.
*   **Interface:** Interactive Streamlit interface featuring dynamic one-hot inference dummy arrays to parse user selections on the fly.

### 2. Smart City AI Traffic Hub
*   **Domain:** Urban Infrastructure Strategy & Time-Series Forecasting
*   **Core Model:** Optimized Extreme Gradient Boosting (XGBoost Regressor)
*   **Evaluation Metric:** **0.97 R² Score**, explaining 97% of total vehicular chronological sequence variance.
*   **Key Engineering Highlight:** Eliminated structural temporal data leaks by engineering dual-axis circular trigonometric spatial-temporal mappings (Sine and Cosine encodings for hours and days).
*   **Interface:** Responsive glassmorphic UI dashboard optimized for mobile browsers, featuring state-isolated execution flags and interactive Plotly time-series tracking.
